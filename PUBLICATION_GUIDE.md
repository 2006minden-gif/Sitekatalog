# 🚀 Публикация сайта на GitHub + Vercel

## 📝 Что мы сделаем:
1. Создадим репозиторий на GitHub
2. Загрузим файлы проекта
3. Подключим Vercel для автоматической публикации
4. Получим публичную ссылку на сайт

---

## ШАГ 1: Создание репозитория на GitHub

### 1.1. Войди на GitHub
- Открой https://github.com
- Войди в свой аккаунт

### 1.2. Создай новый репозиторий
- Нажми на кнопку **"New"** (зелёная кнопка слева) или перейди на https://github.com/new
- Заполни поля:

**Repository name:** `electroopt-website` (или любое другое название)

**Description:** `Корпоративный сайт с B2B-каталогом электронных компонентов`

**Public** ✅ (выбери Public)

**Add a README file** ✅ (поставь галочку)

- Нажми зелёную кнопку **"Create repository"**

### 1.3. Скопируй URL репозитория
- После создания репозитория скопируй URL из адресной строки браузера
- Он будет выглядеть так: `https://github.com/твой-логин/electroopt-website`

---

## ШАГ 2: Загрузка файлов проекта на GitHub

### Вариант А: Через веб-интерфейс (самый простой)

#### 2.1. Открой репозиторий
- Перейди в свой репозиторий на GitHub

#### 2.2. Нажми "Add file" → "Upload files"
- Найди кнопку **"Add file"** (справа вверху)
- Выбери **"Upload files"**

#### 2.3. Загрузи файлы
- Нажми **"choose your files"** или перетащи файлы в окно
- **ВАЖНО:** Загружай ВСЮ папку проекта, КРОМЕ:
  - ❌ `node_modules/` (эта папка не нужна)
  - ❌ `dist/` (эта папка создастся автоматически)
  
- Что нужно загрузить:
  - ✅ Все файлы из корня проекта (package.json, index.html, README.md и т.д.)
  - ✅ Папку `src/` со всем содержимым
  - ✅ Папку `demo/` (если есть)
  - ✅ Файл `.gitignore`

#### 2.4. Подтверди загрузку
- Прокрути вниз
- В поле "Commit changes" напиши: `Initial commit`
- Нажми зелёную кнопку **"Commit changes"**

---

### Вариант Б: Через Git (если установлен Git)

Если у тебя установлен Git, можно загрузить через командную строку:

```bash
# Открой терминал в папке проекта

# Инициализируй Git
git init

# Добавь все файлы
git add .

# Создай первый коммит
git commit -m "Initial commit"

# Добавь удалённый репозиторий (замени URL на свой)
git remote add origin https://github.com/твой-логин/electroopt-website.git

# Загрузи файлы
git branch -M main
git push -u origin main
```

## ШАГ 3: Подключение Vercel для автоматической публикации

### 3.1. Зарегистрируйся на Vercel
- Открой https://vercel.com
- Нажми **"Sign Up"**
- Выбери **"Continue with GitHub"** (рекомендуется)
- Разреши доступ к GitHub

### 3.2. Импортируй проект
- После входа нажми **"Add New..."** → **"Project"**
- Найди свой репозиторий `electroopt-website`
- Нажми **"Import"**

### 3.3. Настрой проект
Vercel автоматически определит настройки. Проверь:

**Framework Preset:** `Vite`

**Build Command:** `npm run build`

**Output Directory:** `dist`

- Нажми **"Deploy"**

### 3.4. Дождись деплоя
- Vercel соберёт проект (это займёт 1-2 минуты)
- Ты увидишь статус: **"Ready"** ✅

### 3.5. Получи ссылку на сайт
- После успешного деплоя Vercel даст тебе ссылку
- Она будет выглядеть так: `https://electroopt-website.vercel.app`
- Или: `https://electroopt-website-твой-логин.vercel.app`

**🎉 ПОЗДРАВЛЯЮ! Твой сайт опубликован!**

## ШАГ 4: Проверка сайта

### 4.1. Открой сайт
- Перейди по ссылке, которую дал Vercel
- Сайт должен открыться

### 4.2. Проверь основные функции
- ✅ Главная страница загружается
- ✅ Каталог товаров работает
- ✅ Поиск и фильтры работают
- ✅ Корзина работает
- ✅ Админ-панель работает (пароль: admin123)

### 4.3. Проверь админ-панель
- Прокрути страницу вниз
- Нажми **"Админ"** в подвале
- Введи пароль: `admin123`
- Попробуй включить режим редактирования

## 🔄 Автоматические обновления

Теперь каждый раз, когда ты загружаешь изменения в GitHub:
1. Vercel автоматически обнаружит изменения
2. Пересоберёт проект
3. Обновит сайт

**Как загрузить изменения:**
1. Открой свой репозиторий на GitHub
2. Нажми на файл, который хочешь изменить
3. Нажми иконку карандаша (Edit)
4. Внеси изменения
5. Нажми **"Commit changes"**
6. Vercel автоматически обновит сайт!

## 🌐 Привязка своего домена (опционально)

Если хочешь использовать свой домен (например, `electroopt.ru`):

### 5.1. Купи домен
- На reg.ru, nic.ru или другом регистраторе
- Стоимость: ~200-900 ₽/год

### 5.2. Привяжи домен к Vercel
- В Vercel открой свой проект
- Перейди в **"Settings"** → **"Domains"**
- Нажми **"Add"**
- Введи свой домен: `electroopt.ru`
- Vercel даст инструкции по настройке DNS

### 5.3. Настрой DNS у регистратора
- Зайди в панель управления доменом
- Добавь DNS-записи, которые дал Vercel
- Обычно это:
  - **A запись:** `76.76.21.21`
  - **CNAME запись:** `cname.vercel-dns.com`

### 5.4. Подожди
- Обновление DNS занимает от 15 минут до 24 часов
- После этого сайт будет доступен по твоему домену

## 📊 Альтернатива: GitHub Pages

Если не хочешь использовать Vercel, можно использовать GitHub Pages:

### Настройка GitHub Pages:
1. Открой репозиторий на GitHub
2. Перейди в **"Settings"** → **"Pages"**
3. В разделе **"Source"** выбери **"GitHub Actions"**
4. Создай файл `.github/workflows/deploy.yml` с настройками деплоя

**Минусы GitHub Pages:**
- Нужно настраивать GitHub Actions
- Менее удобно, чем Vercel
- Нет автоматического HTTPS (нужно настраивать)

**Плюсы Vercel:**
- Автоматический деплой при каждом push
- Автоматический HTTPS
- Быстрая CDN по всему миру
- Бесплатно для личных проектов

## 🆘 Если что-то не работает

### Ошибка: "Build failed"
- Проверь, что все файлы загружены
- Убедись, что `package.json` на месте
- Проверь логи в Vercel

### Ошибка: "404 Not Found"
- Проверь, что проект собран (`npm run build`)
- Убедись, что Output Directory: `dist`

### Сайт не открывается
- Подожди 1-2 минуты после деплоя
- Очисти кэш браузера (Ctrl+Shift+Delete)
- Попробуй в режиме инкогнито
