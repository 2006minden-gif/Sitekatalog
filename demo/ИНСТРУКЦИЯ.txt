========================================
  ЭлектроОпт - Инструкция по запуску
========================================

СПОСОБ 1: Автоматический (рекомендуется)
----------------------------------------
1. Запустите файл: CopyFiles.bat
   (скопирует файлы из папки dist в папку demo)

2. Запустите файл: Launch.bat
   (откроет сайт в браузере)


СПОСОБ 2: Ручной
----------------
1. Откройте папку dist
2. Найдите файл index.html
3. Откройте его в браузере (Chrome, Firefox, Edge)


СПОСОБ 3: Через локальный сервер
--------------------------------
В корне проекта выполните команду:
  npm run preview

Сайт откроется по адресу: http://localhost:4173


========================================
  Доступ к функциям
========================================

АДМИН-ПАНЕЛЬ:
1. Прокрутите страницу вниз
2. Нажмите "Админ" в подвале сайта
3. Введите пароль: admin123

РЕЖИМ РЕДАКТИРОВАНИЯ:
- Нажмите "Режим редактирования" в панели админа
- Кликайте на любой текст для изменения
- Загружайте изображения и документы

УПРАВЛЕНИЕ КАТАЛОГОМ:
- Нажмите "Управление каталогом" в панели админа
- Импорт товаров из Excel
- Добавление/редактирование товаров
