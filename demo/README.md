# Демонстрация сайта «ЭлектроОпт»

## 🚀 Быстрый запуск

### Способ 1: Просто открыть файл
1. Откройте файл `index.html` в любом браузере (Chrome, Firefox, Edge)
2. Сайт готов к демонстрации!

### Способ 2: Через bat-файл (Windows)
1. Дважды кликните на `Запустить сайт.bat`
2. Сайт откроется в браузере по умолчанию

---

## 🔐 Доступ к функциям

### Для обычных пользователей:
- Каталог товаров: `/#/catalog`
- О компании: `/#/about`
- Производители: `/#/manufacturers`
- Новости: `/#/news`
- Контакты: `/#/contacts`
- Корзина: `/#/cart`
- Личный кабинет: `/#/account`

### Для администратора:
1. Нажмите **«Админ»** в подвале сайта (внизу страницы)
2. Введите пароль: **admin123**
3. Откроется плавающая панель управления
4. Нажмите **«Режим редактирования»** для изменения контента
5. Нажмите **«Управление каталогом»** для работы с товарами

---

## ✨ Что можно показать заказчику

### 1. Каталог товаров
- Поиск по названию и парт-номеру
- Фильтры по производителю и категории
- Переключение таблица/сетка
- Добавление в корзину

### 2. Режим редактирования (как в Tilda)
- Кликните на любой текст — он станет редактируемым
- Измените заголовки, описания, контакты
- Загрузите новые изображения
- Добавьте/удалите новости, производителей

### 3. Управление каталогом
- Импорт товаров из Excel
- Экспорт каталога
- Добавление/редактирование товаров
- Статистика по каталогу

### 4. Загрузка документов
- Раздел «Документы» → «Типовые документы»
- Загрузите PDF/DOCX файлы
- Клиенты смогут их скачать

## 📱 Адаптивность

Сайт полностью адаптивен:
- Десктоп (1920x1080 и выше)
- Планшет (768x1024)
- Мобильный (375x667)

Попробуйте изменить размер окна браузера!

---

## 💾 Сохранение данных

Все изменения сохраняются в браузере (localStorage):
- Отредактированный контент
- Загруженные изображения и документы
- Добавленные товары
- Корзина

⚠️ **Важно:** Данные сохраняются только в этом браузере на этом компьютере.

## 🌐 Публикация в интернете

Для публикации сайта в интернете:
1. Купите домен (например, на reg.ru)
2. Выберите хостинг (Vercel, Netlify, или российский хостинг)
3. Загрузите файлы из папки `dist/`
4. Подключите SSL-сертификат

Подробная инструкция в файле `ИНСТРУКЦИЯ_ПО_ПУБЛИКАЦИИ.md`
