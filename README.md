# ЭлектроОпт — Корпоративный B2B-сайт

Корпоративный сайт с B2B-каталогом для оптовой торговли электронными компонентами.

## 🚀 Возможности

### Для пользователей:
- **Каталог товаров** — многоуровневый каталог с фильтрацией и поиском
- **Карточки товаров** — подробная информация, характеристики, наличие
- **Корзина** — оформление заявок на закупку
- **Личный кабинет** — история заказов, документы, уведомления
- **Информационные разделы** — новости, производители, о компании
- **Контакты** — форма обратной связи, контактная информация

### Для администраторов:
- **Inline-редактирование** — редактирование контента прямо на странице (как в Tilda)
- **Редактирование текста** — кликайте на любой текст для изменения
- **Редактирование изображений** — загрузка и замена картинок
- **Редактирование таблиц** — добавление, удаление и изменение строк
- **Редактирование списков** — управление списками преимуществ, истории и т.д.
- **Автоматическое сохранение** — все изменения сохраняются в localStorage

## 🔐 Доступ к админ-панели

### Вход:
1. Перейдите по ссылке `/#/admin` или нажмите "Админ" в футере
2. Введите пароль: **admin123**
3. После входа вы увидите плавающую панель администратора в правом нижнем углу

### Режим редактирования:
1. Нажмите кнопку **"Режим редактирования"** в панели админа
2. Все редактируемые элементы будут подсвечиваться при наведении
3. Кликайте на текст, изображения или таблицы для редактирования
4. Изменения сохраняются автоматически
5. Нажмите **"Режим просмотра"** для выхода из режима редактирования

## 📝 Что можно редактировать

### Главная страница:
- Заголовки и подзаголовки hero-секции
- Статистика (количество товаров, производителей, лет на рынке)
- Преимущества компании (заголовки и описания)
- CTA-секция

### Страница "О компании":
- Hero-секция с описанием
- Статистика
- Миссия компании
- Ключевые компетенции (список)
- Преимущества работы (карточки с иконками)
- История компании (временная шкала)

### Страница "Контакты":
- Информация о компании (название, ИНН, ОГРН, адрес)
- Телефоны и отделы (таблица)
- Email-адреса (таблица)
- График работы
- Фактический адрес

### Изображения:
- Наведите на изображение в режиме редактирования
- Нажмите "Заменить изображение"
- Выберите файл с компьютера
- Изображение автоматически сохранится

### Таблицы:
- Добавление новых строк
- Редактирование существующих данных
- Удаление строк

## 🛠 Технологии

- **React** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Vite** — быстрый сборщик
- **Tailwind CSS** — utility-first CSS фреймворк
- **React Router** — маршрутизация
- **Lucide React** — иконки
- **LocalStorage** — хранение контента и настроек

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## 🔒 Безопасность

⚠️ **Важно:** В текущей реализации пароль хранится на клиенте и данные сохраняются в localStorage браузера. Это демонстрационная версия.

Для продакшена необходимо:
- Перенести авторизацию на сервер
- Использовать базу данных для хранения контента
- Реализовать систему прав доступа
- Добавить резервное копирование данных
