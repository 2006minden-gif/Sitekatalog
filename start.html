Открыть сайт

📋 Инструкция по запуску

  1. Нажмите кнопку "Открыть сайт" выше
  2. Сайт откроется в новой вкладке браузера
  3. Для доступа к админ-панели прокрутите страницу вниз
  4. Нажмите "Админ" в подвале сайта
  5. Введите пароль: admin123

🔐 Доступ к админ-панели

Пароль: admin123

Возможности:

  • Режим редактирования контента (как в Tilda)
  • Управление каталогом товаров
  • Импорт/экспорт из Excel
  • Загрузка документов

💡 Что можно показать заказчику

  • Каталог товаров - поиск, фильтры, добавление в корзину
  • Режим редактирования - изменение любого текста на сайте
  • Управление каталогом - импорт из Excel, добавление товаров
  • Загрузка документов - прикрепление PDF/DOCX файлов
  • Адаптивность - измените размер окна браузера

Если кнопка не работает, откройте файл dist/index.html вручную в браузере.
